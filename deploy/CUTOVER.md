# Switch HR to the website

Run the website beside `GrainHR.bat` for one week. Both use the same shared-drive files. During that week only one person edits staff records and payroll.

Check these against the PC before HR stops using `GrainHR.bat`:

- October or the current month's shop and production totals match.
- One payslip PDF from LibreOffice matches the Word PDF by eye. Chinese names must not turn into boxes.
- A staff edit on the server keeps the dropdowns in Staff_info.
- The late report lists the same people.
- 立即更新 writes a request file and a new DAKA export appears.
- An HR sign-in does not show office salary, net pay, MPF, bank details, the office book, or office payslips.
- An admin sign-in still shows those.

After that week, HR uses the website. Leave `GrainHR.bat` on the shared drive as the backup.
